# BLEDOB Widget — v1.3 (неоновая иконка)

Полный бесплатный Android-проект для BLE-контроллера **BLEDOB / Lotus Lantern**.

- Главное изменение: настоящее изображение `app/src/main/res/drawable/widget_power.png` вместо текстового значка, который отображался прямоугольником.
- Одинаковая неоновая иконка в виджете, ярлыке 1×1 и приложении.
- Сохранены обе версии управления Bluetooth, поиск контроллера и логика включения/выключения.
- Системный виджет может занимать 2×2 на отдельных оболочках Android даже при настройке 1×1. Для одной клетки откройте приложение и выберите «Добавить кнопку 1×1 на рабочий стол». Это ярлык, а не виджет: он не меняет цвет в зависимости от состояния ленты.

## Самый простой способ обновить проект в GitHub

Используйте архив `BLEDOB_v1_3_UPLOAD_GITHUB.zip`: он содержит **весь код приложения**, но не скрытую папку `.github`. В вашем репозитории уже находится рабочий `.github/workflows/build.yml` — он останется неизменным.

1. Распакуйте архив на ПК.
2. Откройте GitHub → ваш репозиторий BLEDOB-Widget → вкладка `Code` → `Add file` → `Upload files`.
3. Перетащите **всё содержимое распакованной папки**, а не сам ZIP-файл. Подтвердите замену уже существующих файлов, если GitHub спросит.
4. Нажмите `Commit changes`.
5. В `Actions` дождитесь зелёной отметки `Build Android APK` → откройте сборку → `Artifacts` → скачайте `BLEDOB-Widget-APK`.
6. Распакуйте скачанный ZIP и установите `app-debug.apk` на телефон.
7. Если телефон отказывает в обновлении из-за другой debug-подписи, удалите старую версию приложения (настройки контроллера придётся выбрать заново), затем установите новую. Удалите старый виджет/ярлык и добавьте новый.

Архив `BLEDOB_v1_3_FULL_SOURCE.zip` содержит также `.github/workflows/build.yml` как резервную полную копию; при обычном обновлении репозитория через браузер использовать его не нужно.

## Источники
Протоколы BLE и код предыдущей успешной сборки сохранены. Android 8+.
