# BLEDOB Widget — бесплатный виджет Android

**Что есть:** одно нажатие на виджет рабочего стола -> отправка команды включить / выключить по Bluetooth Low Energy. Нет интернета, рекламы, платных компонентов, аналитики. Минимум Android 8 (API 26).

## Установка / сборка

1. Распаковать архив и открыть папку `BLEDOB_Widget_Android` в **Android Studio** (File → Open).
2. Дождаться Gradle Sync, при необходимости разрешить Android Studio установить Android SDK 35 / Gradle 8.9.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
4. Скопировать APK на телефон, установить, разрешить доступ к Bluetooth.
5. В приложении «Найти контроллер Bluetooth», выбрать BLEDOB (или ELK-BLEDOB) по имени из списка.
6. Нажать «Проверить: ВКЛ», «Проверить: ВЫКЛ». Закрыть Lotus Lantern перед проверкой.
7. Если не работает, выбрать второй протокол в списке и проверить снова.
8. На главном экране телефона долгое нажатие по пустому месту → Виджеты → BLEDOB Widget → добавить.

**Важно:** состояние отображается по последней успешно отправленной команде. Некоторые контроллеры не сообщают фактический статус. Если управляете из Lotus Lantern или пропало питание, показания могут расходиться с реальностью. Если потеря связи, появится красная надпись «ОШИБКА». Приложение пока не проверено с вашим конкретным экземпляром.

## Протоколы

- Lotus Lantern (по умолчанию), запись в BLE GATT `FFF0/FFF3`:
  - ON: `7E 04 04 01 00 01 FF 00 EF`
  - OFF: `7E 04 04 00 00 00 FF 00 EF`
- BLEDOB / LotusLamp X (запасной вариант), тот же GATT:
  - ON: `7E 07 04 FF 00 01 02 01 EF`
  - OFF: `7E 07 04 00 00 00 02 01 EF`

Источники:
https://github.com/user154lt/ELK-BLEDOM-Command-Util
https://github.com/8none1/elk-bledob

Параметр BLUETOOTH_SCAN `neverForLocation` позволяет не запрашивать местоположение на Android 12+. На Android 11 и ниже для BLE scan требуется разрешение местоположения.

## Ограничения

- В этом архиве **исходники**, а не APK: в среде подготовки отсутствует Android SDK/Gradle, поэтому бинарник не собирался и не тестировался на телефоне.
- Предполагается BLE сервис FFF0, характеристика FFF3. У отдельных аппаратных ревизий бывает иная реализация.
- Время на одну команду Bluetooth до 12 секунд, отключает соединение после записи.
- Приложение может не подключиться, пока штатный Lotus Lantern держит контроллер.

Альтернатива Android Studio: загрузить содержимое проекта в репозиторий GitHub, открыть вкладку **Actions** → **Build Android APK** → Run workflow. После завершения скачать артефакт **BLEDOB-Widget-APK**. Этот способ тоже бесплатен в рамках доступных лимитов GitHub Actions.
