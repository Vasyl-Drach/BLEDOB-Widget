# BLEDOB Widget 1.4 — прозрачная иконка и быстрый ярлык

## Исправления

1. Виджет теперь не рисует серую подложку — используется настоящий прозрачный PNG `widget_power.png`.
2. Виджет запрашивает минимальный размер 1×1 (`minWidth/minHeight=1dp`, `targetCell=1×1`). **Некоторые лаунчеры (в частности Xiaomi/MIUI/HyperOS) могут всё равно выделять 2×2.** Приложение не способно принудительно изменить сетку чужого лаунчера.
3. Добавлен новый **ярлык 1×1**, который запускает невидимый `ToggleActivity` (`Theme.NoDisplay`): экран настроек при нажатии **не открывается**. Переключение делает исходный BLE-сервис.
4. BLE-команды, MAC-адрес, выбор протокола и разрешения остались без изменений.

## Установка через GitHub

1. Открой `https://github.com/Vasyl-Drach/BLEDOB-Widget`.
2. Загрузи содержимое ZIP `BLEDOB_v1_4_UPLOAD_GITHUB.zip` в корень репозитория и подтверди замену старых файлов. **Не загружай ZIP как один файл.**
3. Существующий `.github/workflows/build.yml` остаётся на месте. Он уже собирал предыдущую версию. Если нужен новый репозиторий, полный архив с workflow — `BLEDOB_v1_4_FULL_SOURCE.zip`. На сайте GitHub скрытую `.github` папку можно создать вручную, как раньше.
4. В Actions дождись успешной сборки; скачай `BLEDOB-Widget-APK`, извлеки APK и установи.
5. Если Android сообщает, что обновление не устанавливается, причина обычно в смене автоматически сгенерированного debug-ключа между запусками GitHub Actions. Тогда удали старую версию приложения, установи новую и заново выбери BLEDOB. Не отключай Play Protect целиком.
6. **Удаляй старые виджет и ярлык с рабочего стола и добавляй новые после установки**, чтобы лаунчер обновил размер и ярлык.
7. Открой приложение, выбери BLEDOB (если требуется), нажми `Добавить кнопку 1×1 на рабочий стол`. Подтверди создание ярлыка.
8. Нажимай новый ярлык: экран приложения не должен появляться. Уведомление BLE-сервиса может появиться ненадолго, это штатно.

## Про прозрачность

Проверено: PNG содержит альфа-канал. Фон `widget.xml` выставлен в `@android:color/transparent`, и `LedWidgetProvider.java` больше не закрашивает его серым. Лаунчер может самостоятельно придавать фон **обычным значкам/ярлыкам**: такая системная подложка не находится в файле PNG и управляется настройками телефона.

## Ограничения

- Размер 1×1 для *виджета* нельзя гарантировать на каждой оболочке. 1×1 для *закреплённого ярлыка* — это стандартная иконка рабочего стола.
- Ярлыки Android запускают Activity, но здесь она невидима и закрывается в `onCreate`; BLE-команду передаёт foreground-service.
- Компиляция APK и реальное поведение MIUI/HyperOS в этой среде не проверены. Исходники проверены на структуру XML, наличие ресурсов и целостность архива.
- Проверяй на реальном телефоне; если ярлык всё равно отображает интерфейс, пришли скрин или видео и версию оболочки.
